# 🛒 Customer Behaviour Analysis

## 📌 Project Overview

This project analyzes customer purchasing behaviour using:

- Python for data cleaning and preprocessing
- SQL for business insights and querying
- Power BI for interactive dashboard visualization

The goal of this project is to uncover customer trends, spending patterns, product performance, and location-based insights.

---

# 🚀 Technologies Used

- Python
- Pandas
- NumPy

- MySQL
- Power BI

# 🔍 Key Insights

- Total Customers: 5K
- Total Spend: 994K+
- Average Spend: 198.84
- Electronics generated highest revenue
- Female customers contributed major revenue share
- Spring, Winter, and Summer showed highest seasonal revenue
- Debit Card was the most used payment method
